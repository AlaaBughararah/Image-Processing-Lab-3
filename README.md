# Image Processing Lab 3

## Geometric & Intensity Transformations

This lab demonstrates basic image processing techniques using Python and the PIL library.

### Geometric Transformations
- Image Scaling
- Non-uniform Scaling
- Rotation
- X-axis and Y-axis Shearing
- Combined X and Y Shearing

### Intensity Transformations
- Image Negative
- Log Transformation
- Power-Law (Gamma) Correction

The lab explores how different geometric and intensity transformations affect a grayscale image and compares the resulting outputs.
